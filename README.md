# 📰 Tanah Merah News!

Modern News Portal with Next.js 15, NestJS, and PostgreSQL.

## 🚀 Quick Start

### Backend
1. `cd backend`
2. `npm install`
3. `npm run seed`
4. `npm run start:dev`

### Frontend
1. `cd frontend`
2. `npm install`
3. `npm run dev`

Detailed documentation can be found in `PROJECT_DOCUMENTATION.md`.
